# Claude Launcher

Chrome extension that opens [claude.ai](https://claude.ai) in a new tab with one click or keyboard shortcut.

## Features

- Toolbar button → opens Claude in a new tab
- Keyboard shortcut: `Alt+C`
- Configurable via options page

## Tech Stack

Chrome Extension (Manifest V3), vanilla JavaScript

## Install

1. Clone this repo
2. Go to `chrome://extensions/` → Enable Developer Mode
3. Click "Load unpacked" → select the repo folder
